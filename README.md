# Meetia Infra

Repositorio de infraestructura y despliegue de Meetia.  
Este proyecto centraliza la configuración de contenedores, redes y servicios necesarios para ejecutar la plataforma en entornos de desarrollo y producción.

---

## 🏗️ Arquitectura

La infraestructura está basada en contenedores Docker orquestados mediante Docker Compose.

```text
Frontend (React)
        ↓
Backend API (Node.js + Prisma)
        ↓
PostgreSQL
```
---

## 🛠️ Tecnologías utilizadas

(De forma provisoria)

- Docker
- Docker Compose
- PostgreSQL
- Prisma ORM
- Node.js
- Express
- React
- OpenStreetMap
- Leaflet
